# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of background, identity, experience, or viewpoint.

## Expected behavior

- Be respectful and constructive.
- Assume good faith while discussing technical disagreements.
- Focus on evidence, reproducible behavior, and user impact.
- Accept correction and feedback professionally.
- Protect private information and security reports.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, personal attacks, and public disclosure of private security reports are not acceptable.

## Enforcement

Report serious or repeated violations privately to the repository maintainers. Security vulnerabilities must follow SECURITY.md rather than public issue reporting.
